## **개발 과정**
### 1. 데이터 수집 및 특징 추출
BigQuery는 모든 로그 중 AI가 학습할 수 있는 의미 있는 feature를 뽑아내도록 함
- 사용자의 로그인 시각, 접근한 폴더의 보안 등급, 파일 다운로드 횟수, 평소와 다른 시간대의 접속 여부 등을 수집함
- 이 데이터는 일정한 시간 단위(예: 10분)의 묶음(Window)으로 가공되어 AI 모델인 Autoencoder의 입력값으로 전달함

### 2. 이상 패턴 감지
Autoencoder는 정상 행동 복원기
- 정상적인 사용자의 패턴만 학습함
- 이상 패턴이 들어오면 복원을 제대로 하지 못해 복원 오차 발생
- 행동 데이터에 대해 오차 수치 전달

### 3. 위험 점수 산정
AI가 내뱉은 오차 수치를 사람이 이해할 수 있는 Risk Score로 변환함
- 점수화: 오차가 크면 위험 점수 상승
- 감쇠(Decay): 시간이 지나 추가적인 이상 징후가 없으면 점수가 자연스럽게 줄어들도록 설계
    - 보안 모드가 계속 ALERT로 유지되는 것을 방지
- 계산된 최종 점수는 시스템의 보안 모드를 결정함

### 4. 능동형 보안 전환 및 알림
최종 점수에 따라 시스템은 스스로 대응 수위를 조절
- 동작 (각각 어떤 블락을 실행할지 결정 필요)
    - SAFE (정상): 평상시
    - WATCH (주의)
    - ALERT (경보) : 관리자에게 즉시 구글 챗 전송

### 요약
1. BigQuery가 행동 로그를 숫자로 바꾸어 전달
2. Autoencoder가 그 숫자가 평소와 얼마나 다른지(오차) 계산
3. Risk Score 로직이 이 오차를 바탕으로 실시간 위험 점수 산출
4. 보안 모드 로직이 점수에 따라 기능을 차단하거나 구글 챗 전송

## 사용법
python -m autoencoder.anomaly_scoring --input "input_sample_name.csv" --output "output_name.csv"
